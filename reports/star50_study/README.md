# 科创50 单日大跌利空归因与预警模型

研究科创50指数（000688.SH）自 2020-07-23 发布以来所有**单日跌幅 ≥1.5% 的交易日**（259 天，
归并为 **91 个下跌事件簇**），为每一簇找到利空催化剂并标注置信度，在此基础上构建可每日运行的
利空预警打分模型（v1.1）。

**主报告**：`科创50单日大跌利空归因与预警模型.html`（浏览器直接打开；数据窗口 2020-07-01 → 最新交易日）

## 核心发现

- 大跌是常态：17.2% 的交易日跌幅≥1.5%；任意 5 日窗口出现此类大跌的概率 56.6%。
- 最致命的是"内生拥挤"：板块自身拥挤瓦解（IPO 抽血/指数调仓/抱团瓦解）与流动性踩踏
  （雪球敲入/量化强平/汇率急贬）造成的簇跌幅最深，且 T+5 仍偏弱（-0.81%/-0.77%）；
  而"政策卖事实"与纯技术性回调反弹最快（+1.38%/+1.01%）。
- 预警主力是 E1 过热因子（20日涨幅>10% 且放量）：全样本命中 85.2%，**样本外（2024-01 起）
  83.6%**；趋势/连跌/平静三条件被证实为非信号。
- 外生冲击（对等关税、中东战争）事前不可测但当日获护盘修复；内生拥挤可预警但易踩踏——
  模型 = E1 量化预警 + 事件因子升级 + 仓位纪律。

## 日常使用（每日收盘后 1 分钟）

```bash
python3 daily_score.py --soxx <隔夜SOXX%> --qqq <隔夜QQQ%> --fx10d <USDCNH10日涨幅%>
# 事件命中加开关：--b1 --b2 --c1 --c2 --e2 --e3 --e4 --e1a --a1a --pe-percentile 90
```

输出总分 → 级别（Ⅰ绿 0-2 / Ⅱ黄 3-5 / Ⅲ橙 6-8 / Ⅳ红 ≥9）→ 当日仓位纪律。
盘前事件扫描（B/C/E2 类因子）的 6 步清单与全部数据源调用语句见 HANDOFF §0.6。

## 数据更新与报告重建

```bash
# 1) 新交易日追加到 star50_index.csv（两份副本同步，见 HANDOFF §0.2）
# 2) 重算底稿（干跑核对后再落盘）
python3 build_artifacts.py && python3 build_artifacts.py --write
# 3) 重建报告
python3 build_report.py
```

新发生的大跌日按 HANDOFF §0.2 归因后追加进对应年份 JSON（episode_id 接续编号）。
