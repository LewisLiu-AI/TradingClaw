# 策略冻结说明（STRATEGY.md）

> 这是 301526 国际复材波段策略的**冻结规格书**。研究过程与论证见 [REPORT.md](REPORT.md)，
> 全部数字出自 2024-06-03~2026-09-11（556 个交易日）、含 A 股完整交易成本。
> ⚠️ **第 14 节勘误**修正了旧脚本的方法学缺陷，本文件采用修正后的数字。

## 1. 冻结的规则

```
【核心 L1+L2】趋势滞回带（收益引擎，唯一稳健有效的层）
  空仓 → 持仓 : 收盘 > MA20 × (1 + buy_band)  且  MA20 > MA60
  持仓 → 空仓 : 收盘 < MA20 × (1 - sell_band) 或  MA20 < MA60
  中间地带（MA20 上下 buy/sell_band 之内）: 维持原状态     ← 抗震荡的关键
  默认 buy_band = sell_band = 0.05

【先手层 L3】空仓时用小仓抢反弹（未确认，故 0.7 仓）
  B1 系统性恐慌: dd_high20 < -13% 且 ret5 < -6% 且 创业板指5日 < -1.5% 且 ATR% > 4
  B2 个股崩跌  : dd_high20 < -35% 且 ret5 < -10% 且 RSI14 < 45
  （A 趋势回踩 / B3 强势急回踩 / C 突破 作为先手入场: 见 §4 说明）

【风控层 L4】默认关闭
  顶部减仓（过热 / 杠杆换手极端 / 大宗折价派发）与追踪止损均为可选，
  默认关闭 —— 统计上能识别顶（召回 93%），但接进交易会亏掉主升。
```

**时序**：所有信号在 T 日收盘生成，T+1 开盘成交。交易所晚间披露的数据（融资融券、龙虎榜、大宗）
统一 `shift(1)` 使用；股东户数按报告期 +45 天滞后。**无前视。**

**成本**：佣金万 2.5 双边 + 印花税卖出 0.05% + 过户费 0.001% 双边 + 滑点 0.1%；
整股成交；开盘触及涨跌停（±19.9%，主板请改 0.099）不可成交。

## 3. 必须先做适用性体检（最重要的一步）

**这套规则只在"长而干净的多段趋势"上有效。** 20 只同类标的原样搬家测试：捕获率
（策略收益 / 买入持有收益）**中位仅 0.36**，只有 1 只跑赢买入持有。

```bash
python swing_strategy.py --csv <目标标的.csv> --market data/idx_cyb.csv --check
# 或批量
python swing_strategy.py --batch data/peers/ --market data/idx_cyb.csv --check
```

| 捕获率 | 处置 |
|---|---|
| **> 0.7** | 适配，可用完整配置（含先手层） |
| **0.4 ~ 0.7** | 只当**风控叠加层**（接受收益让渡换回撤控制） |
| **< 0.4** | 不要用趋势过滤。改用 `aggressive_trail`（满仓 + 2.0~2.5×ATR 追踪）或长期持有 |

已在 301526 上验证：捕获率 1.23（20 只里唯一 >1）。

## 4. 三条已验证的"不要做"

1. **不要按顶部信号减仓/清仓**：全样本 823% → 446%（减仓）/ 357%（清仓），回撤只从 -28.9%
   改善到 -24.5%/-37.2%。强趋势股上过早下车的代价远大于躲过回撤的收益。
2. **不要用宏观/月份择时来提收益**：14 个市场层面变量对"先手层是否有效"的解释力 |Spearman| ≤ 0.23；
   跨资产（黄金/原油/美债/VIX/费半/纳指/铜/恒生）同样如此。唯一稳定的是「沪市两融20日变化>0」，
   它的价值是**砍交易数（-42%）**，不是提高收益。
3. **不要指望波动率归一化解决问题**：把买带/卖带/止损全部改成按 ATR% 缩放，捕获率与固定版
   完全持平（0.36 vs 0.36），回撤甚至更差。问题不在阈值标定，而在标的的趋势形态。

## 6. 已知局限

- 单标的、556 个交易日、纯趋势版仅 5 笔交易 —— 统计量置信区间很宽。
- 2025/2026 的形态在设计时都看过，"样本外 2026"不是严格盲测。
- 参数虽经 ±20% 敏感性检验（ΔCalmar 标准差 0.16）仍属少量样本上的选择。
- 未建模停牌、冲击成本；滑点取 0.1%，而该股日均振幅 8.5%，极端日实际成本更高。
- 策略当前（2026-09-11）为**空仓**（MA20 < MA60）；**2026-12-28 解禁 23.66 亿股
  （占总股本 62.8%、占流通市值 168.5%）** 是最大的结构性风险点。
